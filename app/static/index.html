PhytoAI-Genetics: Pemodelan Transformer Mutasi OsDREB2A (ΔLLR)
Model representasi Protein Language Model (ESM-2 / ProtTrans) untuk memprediksi perubahan energi bebas evolusioner (ΔLLR) mutasi titik pada faktor transkripsi OsDREB2A (NCBI Gene ID: 4324418).
📐 Formulasi Matematis Log-Likelihood Ratio (ΔLLR) & Stabilitas Biofisik: Biophysical Fitness Metric
ΔLLR(xwt → xmut | x) = log [ P(Xi = xmut | x-i) / P(Xi = xwt | x-i) ] = zi(xmut) - zi(xwt) ≈ - ΔΔG / (kBT)
• ΔLLR > +0.50 (Gain-of-Function): Mutasi menstabilkan pelipatan protein atau meningkatkan afinitas pengikatan promoter (mis. P168L ΔLLR = +2.45, konstitutif aktif DREB2A-CA).
• ΔLLR < -1.00 (Loss-of-Function): Mutasi merusak konformasi tersier atau memutus kontak spesifik DNA motif DRE/CRT (mis. V79A ΔLLR = -2.60).

📐 2. Landasan Teori, Formula Biofisika & Contoh Soal dengan Penyelesaian

Berikut adalah penjelasan matematika, termodinamika biofisika, dan pemodelan komputasional yang mendasari setiap formula di dalam sistem, dilengkapi contoh soal studi kasus riil padi Indonesia beserta langkah penyelesaian analitis terperinci:

2.1. Formula Log-Likelihood Ratio (ΔLLR) & Stabilitas Energi Bebas Gibbs (ΔΔG)
ΔLLR(xwt → xmut | x) = ln [ P(Xi = xmut | x-i) / P(Xi = xwt | x-i) ] = zi(xmut) - zi(xwt)
ΔΔG ≈ - kB • T • ΔLLR
Keterangan Variabel:
• x : Sekuens lengkap protein faktor transkripsi OsDREB2A (274 residu asam amino).
• x-i : Konteks sekuens asam amino yang mengapit posisi target ke-i (menangkap interaksi spasial 3D via mekanisme self-attention Transformer).
• zi(x) : Unnormalized log-probability (logit output) yang dihasilkan oleh representasi Protein Language Model (ESM-2 / ProtTrans).
• kB : Konstanta Boltzmann (1,987 × 10-3 kcal/(mol·K)).
• T : Suhu absolut dalam Kelvin (T = 298,15 K pada kondisi standar laboratorium, kBT ≈ 0,593 kcal/mol).
• ΔΔG : Perubahan energi bebas pelipatan protein (ΔGmut − ΔGwt). Nilai ΔΔG < 0 berarti mutasi bersifat eksergonik/menstabilkan struktur protein.
Contoh Soal 1: Pemodelan Biofisik Mutasi DREB2A-CA di Sawah Demak
Kasus Soal:
Pada sentra padi sawah tadah hujan di Kabupaten Demak, Jawa Tengah, tanaman varietas Inpari 32 HDB sering mengalami gagal panen (puso) saat kemarau akibat degradasi cepat protein OsDREB2A oleh enzim ubiquitin ligase E3 proteasom 26S. Untuk membentuk varian konstitutif aktif (DREB2A-CA), dirancang mutasi titik pada residu Prolin posisi 168 menjadi Leusin (P168L) di dalam domain NRD (Negative Regulatory Domain).

Model representasi Transformer pLM menghasilkan logit prediksi:
• Logit residu mutan: z168(Leu) = +4.82
• Logit residu wild-type: z168(Pro) = +2.37
• Suhu fisiologis sawah tropis: T = 300 K (sehingga kBT ≈ 0.596 kcal/mol).

Pertanyaan:
1. Hitung nilai log-likelihood ratio (ΔLLR) mutasi P168L tersebut!
2. Hitung estimasi perubahan energi bebas pelipatan (ΔΔG) dalam satuan kcal/mol!
3. Berikan interpretasi biokimia apakah mutasi ini bersifat Gain-of-Function dan jelaskan mekanisme molekulernya dalam mencegah degradasi proteasom!
Penyelesaian Langkah Demi Langkah:
1Menghitung Skor ΔLLR:
Berdasarkan formulasi rasio probabilitas logaritma Transformer pLM:
ΔLLR = z168(Leu) - z168(Pro) = 4.82 - 2.37 = +2.45
Hasil: Nilai ΔLLR = +2.45 jauh melampaui ambang batas positif (+1.00), mengindikasikan bahwa substitusi Leusin sangat disukai secara evolusioner.
2Menghitung Perubahan Energi Bebas Pelipatan (ΔΔG):
Menggunakan hubungan termodinamika Boltzmann:
ΔΔG ≈ - kBT • ΔLLR = - (0.596 kcal/mol) × (+2.45) = -1.460 kcal/mol
Hasil: Nilai ΔΔG = -1.46 kcal/mol bernilai negatif (ΔΔG < 0), membuktikan bahwa mutasi ini meningkatkan stabilitas struktural konformasi protein (eksergonik).
3Interpretasi Mekanisme Biokimiawi & Molekuler:
Residu Prolin-168 terletak di dalam motif degron PEST-like (160-ESPPFIV-166). Cincin pirolidin kaku pada Prolin secara alami dikenali oleh enzim RING-finger E3 ubiquitin ligase untuk memicu poliubiquitinasi dan degradasi via proteasom 26S dalam kurun waktu < 48 jam.
Dengan substitusi ke Leusin (P168L):
• Rantai samping hidrofobik alifatik Leusin mengganggu geometri pengenalan degron oleh ligase E3 secara sterik.
• Protein OsDREB2A terbebas dari ubiquitinasi, membentuk varian DREB2A-CA (Constitutively Active).
• Akumulasi protein di inti sel tetap stabil dalam konsentrasi tinggi bahkan sebelum cekaman terjadi, menginduksi transkripsi dini gen efektor hilir seperti OsLEA3-1 dan OsAREB1, sehingga padi varietas Inpari 32 HDB dapat mempertahankan turgor sel dan kelangsungan hidup di lahan sawah retak Demak.
2.2. Formula Jarak Geospasial Haversine & Kalibrasi Bahaya InaRISK
a = sin2(Δφ / 2) + cos(φ1) • cos(φ2) • sin2(Δλ / 2)
c = 2 • atan2( √a, √(1 - a) )
d = R • c   (R = 6.371,0 km)
Aturan Kalibrasi Bahaya Spasial BNPB InaRISK Berbobot Jarak:
Untuk titik koordinat bebas di seluruh kepulauan Indonesia, skor bahaya dikalibrasi terhadap klaster sentra terdekat berdasarkan radius pengaruh mikroklimat:
• Jika d ≤ 200 km : Hcal = Hbase (Skor bahaya penuh).
• Jika 200 km < d ≤ 400 km : Hcal = max(0.58, Hbase - 0.06).
• Jika d > 400 km : Hcal = max(0.50, Hbase - 0.12).
• Kategori Bahaya: ≥ 0.85 = Sangat Tinggi / Ekstrem, 0.70 - 0.84 = Tinggi, 0.50 - 0.69 = Sedang.
Contoh Soal 2: Penilaian Koordinat Bebas Sawah Sayung vs Klaster Demak
Kasus Soal:
Seorang penyuluh pertanian melakukan survei di areal persawahan terdampak kekeringan di Kecamatan Sayung, Demak pada koordinat GPS: φ1 = -6.9120°, λ1 = 110.5120°. Pusat klaster sentra padi kekeringan terdekat di database adalah Klaster Demak-Pati pada koordinat: φ2 = -6.8900°, λ2 = 110.6400° dengan skor bahaya dasar BNPB Hbase = 0.88. Radius bumi R = 6.371,0 km.

Pertanyaan:
1. Hitung jarak spasial lingkaran besar (d) dalam kilometer menggunakan rumus Haversine!
2. Tentukan skor bahaya terkalibrasi (Hcal) dan kategori tingkat kekeringan BNPB InaRISK!
3. Berikan rekomendasi kultivar lokal adaptif dan strategi modifikasi faktor transkripsi OsDREB2A!
Penyelesaian Langkah Demi Langkah:
1Konversi Koordinat ke Radian & Hitung Nilai a:
Selisih lintang dan bujur dalam derajat:
Δφ = -6.8900° - (-6.9120°) = +0.0220° → 0.00038397 rad
Δλ = 110.6400° - 110.5120° = +0.1280° → 0.00223402 rad
φ1 = -0.120637 rad, φ2 = -0.120253 rad.

Substitusi ke komponen Haversine a:
sin2(Δφ/2) = sin2(0.00019198) = 3.6858 × 10-8
cos(φ1) • cos(φ2) = 0.98547 • 0.98556 = 0.97125
sin2(Δλ/2) = sin2(0.00111701) = 1.2477 × 10-6
a = 3.6858 × 10-8 + (0.97125 × 1.2477 × 10-6) = 1.2486 × 10-6
2Menghitung Jarak Lingkaran Besar (d):
c = 2 • asin(√1.2486 × 10-6) = 2 • (0.0011174) = 0.0022348 rad
d = 6.371,0 km × 0.0022348 = 14,24 km
Hasil: Jarak titik sawah Sayung ke pusat sentra klaster Demak-Pati adalah 14,24 km.
3Evaluasi Skor InaRISK & Rekomendasi Agroekosistem:
Karena jarak d = 14,24 km ≤ 200 km, maka berlaku bobot penuh tanpa atenuasi:
• Hcal = Hbase = 0.88.
• Kategori Bahaya: SANGAT TINGGI (Extreme Hazard).
• Agroekosistem: Sawah tadah hujan tanah vertisol (lempung berat mudah retak saat defisit air).
• Kultivar Rekomendasi: Inpari 32 HDB atau varietas gogo toleran Situ Bagendit.
• Rekomendasi Genetik: Mutasi P168L melalui Cytosine Base Editor (CBE) untuk mematikan degradasi proteasom NRD, memastikan tanaman tidak puso saat pengisian bulir padi kemarau.
2.3. Formula Termodinamika sgRNA CRISPR: Kandungan %GC dan Melting Temperature (Tm)
%GC = [ (NG + NC) / L ] × 100%
Tm = 64.9 + [ 41 • (NG + NC - 16.4) / L ]
Standar Kelayakan Panduan sgRNA (Golden Rules Bioinformatika CRISPR):
• L = 20 nt : Panjang protospacer standar SpCas9.
• Rentang %GC Ideal: 40% - 60%. Di bawah 40% penempelan ke target genomik lemah; di atas 70% berisiko membentuk struktur sekunder kaku (*hairpin*).
• Rentang Tm Ideal: 45°C - 65°C.
• Filter Pol III Terminator: Sekuens protospacer tidak boleh mengandung motif 4 timidin berurutan (`TTTT`) karena promotor RNA Pol III tanaman padi (OsU6/OsU3) akan menghentikan transkripsi secara prematur.
Contoh Soal 3: Desain Bioinformatika Protospacer Mutasi P168L
Kasus Soal:
Untuk mengintroduksi mutasi penstabil P168L pada sekuens coding (CDS) OsDREB2A (NCBI ID: 4324418), dirancang protospacer 20 nukleotida yang berdekatan dengan motif PAM SpCas9 (5'-AGG-3'):
Sekuens protospacer: 5'- C C C C C T T T A T T G T T G C C A A T G -3'

Pertanyaan:
1. Hitung jumlah setiap nukleotida (NA, NT, NG, NC) dan persentase kandungan %GC!
2. Hitung perkiraan suhu leleh heteroduplex RNA:DNA (Tm) dengan formula Wallace-Breslauer empiris!
3. Periksa apakah protospacer ini memiliki motif terminasi dini Polimerase III (`TTTT`) dan simpulkan apakah oligo ini layak disintesis!
Penyelesaian Langkah Demi Langkah:
1Menghitung Komposisi Basa & %GC:
Panjang protospacer L = 20 nukleotida.
Pencacahan nukleotida:
• Adenin (A) = 3 basa (posisi 9, 17, 18)
• Timin (T) = 8 basa (posisi 6, 7, 8, 10, 11, 13, 14, 19)
• Guanin (G) = 3 basa (posisi 12, 15, 20)
• Sitosin (C) = 6 basa (posisi 1, 2, 3, 4, 5, 16)
Total G + C = 3 + 6 = 9 nukleotida.
%GC = (9 / 20) × 100% = 45.0%
Evaluasi: %GC = 45.0% berada tepat di rentang emas (40% - 60%), menandakan afinitas hibridisasi optimal tanpa agregasi sekunder.
2Menghitung Suhu Leleh (Tm):
Tm = 64.9 + [ 41 • (9 - 16.4) / 20 ] = 64.9 + [ 41 • (-7.4) / 20 ]
Tm = 64.9 + [ -303.4 / 20 ] = 64.9 - 15.17 = 49.73°C
Evaluasi: Suhu leleh Tm ≈ 49.7°C berada dalam rentang fisiologis sel tanaman padi (45°C - 65°C), menjamin spesifisitas pengenalan target oleh kompleks nuklease.
3Pemeriksaan Sinyal Terminasi RNA Pol III & Kesimpulan:
Runtunan timidin (T-run) terpanjang pada sekuens adalah TTT (3 timidin berturut-turut pada posisi 6-8). Tidak ditemukan tetranukleotida TTTT (4 timidin berturut-turut).
Kesimpulan: sgRNA ini SANGAT LAYAK (Highly Recommended) untuk dikloning ke dalam vektor ekspresi plasmid CRISPR tanaman (mis. pCAMBIA atau pZH_gOsU3) dan ditransformasikan via Agrobacterium tumefaciens ke kalus padi lokal.
2.4. Formula Jendela Deaminasi Base Editing (CBE/ABE Windowing)
Wedit = [ pstart , pend ]   relatif terhadap ujung 5' protospacer (posisi 1 s/d 20)
Aktivitas Maksimal: p ∈ [ 4 , 8 ]   |   PAM NGG di posisi [ 21 , 23 ]
Mekanisme Deaminasi Bebas Double-Strand Break (DSB):
• CBE (Cytosine Base Editor): Menggunakan sitidin deaminase (mis. APOBEC1 / EvoFERNY) yang memotong gugus amina dari Sitosin (C) menghasilkan Urasil (U). U dipasangkan dengan A, yang pada replikasi berikutnya menjadi Timin (T). Transisi permanen: C • G → T • A.
• ABE (Adenine Base Editor): Menggunakan adenosin deaminase (mis. TadA-8e) yang mendeaminasi Adenin (A) menjadi Inosin (I). Ribosom dan polimerase membaca I sebagai Guanin (G). Transisi permanen: A • T → G • C.
• Keunggulan mutlak dibanding CRISPR standar: Tanpa pemotongan untai ganda DNA (DSB-free), mencegah terjadinya mutasi insersi/delesi acak (indels) dan translokasi kromosom yang dapat merusak viabilitas benih padi.
Contoh Soal 4: Pemetaan Jendela Deaminasi Kodon CCG ke CTG
Kasus Soal:
Kodon wild-type *OsDREB2A* untuk residu Prolin-168 pada CDS adalah 5'- C4 C5 G6 -3' (terletak pada nukleotida ke-4, ke-5, dan ke-6 dari ujung 5' protospacer). Untuk mengubah Prolin menjadi Leusin (mutasi P168L), kodon harus bertransisi menjadi 5'- C4 T5 G6 -3'.

Pertanyaan:
1. Basa sitosin mana yang harus mengalami deaminasi hidrolitik? Berapa nomor posisinya dari ujung 5' protospacer?
2. Apakah posisi nukleotida target tersebut berada di dalam jendela deaminasi aktif enzim sitidin deaminase (Wedit = [4, 8])?
3. Jelaskan tahapan biokimia pembentukan pasangan basa stabil T:A dari C:G setelah dua putaran replikasi sel meristem apikal padi!
Penyelesaian Langkah Demi Langkah:
1Identifikasi Basa Target:
Kodon Prolin: C4 - C5 - G6.
Kodon Leusin: C4 - T5 - G6.
Basa yang harus diubah adalah Sitosin kedua pada posisi ke-5 (C5 → T5), sedangkan Sitosin pertama pada posisi ke-4 (C4) dipertahankan.
2Validasi Jendela Deaminasi Enzimatis:
Jendela deaminasi aktif untuk Cytosine Base Editor (mis. evoAPOBEC1-nCas9) adalah nukleotida 4 s/d 8 dihitung dari ujung 5' protospacer.
Karena posisi target adalah p = 5, maka 5 ∈ [4, 8]. Posisi ini berada tepat di zona efisiensi deaminasi maksimal (> 65% efisiensi konversi pada tanaman padi).
3Tahapan Kimiawi Reaksi Deaminasi:
1. Deaminasi Hidrolitik: Enzim sitidin deaminase melepaskan gugus amina (-NH2) dari cincin sitosin pada posisi atom C5, mengubah sitosin menjadi urasil (U). Terbentuk pasangan antara U : G.
2. Inhibisi Perbaikan Eksisi Basa: Fusi peptida UGI (*Uracil Glycosylase Inhibitor*) pada arsitektur CBE memblokir enzim seluler UNG padi agar urasil tidak dipotong.
3. Nicking Untai Non-Target: Domain nCas9 (D10A nickase) memotong untai DNA yang mengandung G, merangsang sel untuk menggunakan untai pembawa U sebagai cetakan sintesis perbaikan DNA, memasangkan Adenin (A) di seberang U → terbentuk pasangan U : A.
4. Replikasi DNA Final: Pada siklus pembelahan sel berikutnya, DNA polimerase membaca U sebagai T, menghasilkan pasangan basa kanonikal T : A yang permanen dan stabil diwariskan ke generasi tanaman padi berikutnya.
🌾 3. Biologi Molekuler OsDREB2A & Regulon Cekaman Kekeringan Padi

GENOMIK

BNPB InaRISK & Leaflet Engine

CRISPR Base Editing Designer (CBE/ABE)
Algoritma perancangan protospacer sgRNA 20 nt untuk SpCas9 (NGG) dan SpCas9-NG (NG), pemodelan jendela aktivitas deaminasi nukleotida C→T (CBE) dan A→G (ABE), serta perhitungan termodinamika suhu leleh (Tm).

Metode D: Reverse Proxy Nginx & Sertifikasi SSL Let's Encrypt
Contoh konfigurasi virtual host Nginx untuk mengarahkan trafik HTTPS port 443 ke port internal 8000: 
server {
    listen 80;
    server_name phytoai.yourdomain.ac.id;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name phytoai.yourdomain.ac.id;

    ssl_certificate /etc/letsencrypt/live/phytoai.yourdomain.ac.id/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/phytoai.yourdomain.ac.id/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
